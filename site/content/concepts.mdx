# 개념

메이트를 이해하는 데 필요한 세 가지 개념입니다.

## 스펙류 vs 이력류

메이트의 조회 명령은 필요한 전제조건에 따라 두 갈래로 나뉩니다.

|  | 스펙류 | 이력류 |
|---|---|---|
| 명령 | `/스펙` · `/아이템` · `/유니온` | `/스타포스` · `/잠재` |
| 전제조건 | 캐릭터 등록 | 개인 API 키 등록 |
| 성격 | **현재 상태** 스냅샷 | **누적 이력**(계정 전체) |
| 예 | 지금 전투력·장비·유니온 | 지금까지 쓴 스타포스·큐브 지출 |

**스펙류**는 캐릭터를 등록만 하면 누구나 조회할 수 있는 공개 정보입니다.
지금 이 순간의 전투력·장비·유니온 같은 현재 상태를 보여줘요.

**이력류**는 그동안 스타포스·잠재에 쓴 시도와 메소가 얼마인지 **누적 기록**을
계정 단위로 집계합니다. 이 데이터는 계정 소유자만 볼 수 있어 개인 API 키가 필요해요.

<Callout type="info">
  스타포스 이력은 **11성 이상 강화만** 집계하고, 파괴 감소 이벤트 여부를 반영해
  운빨 지수를 계산합니다. 자세한 규칙은 `/스타포스` 결과의 안내 문구를 참고하세요.
</Callout>

## 개인 API 키

이력류·스케줄러가 다루는 데이터는 넥슨이 **계정 소유자에게만** 열어 주는
개인 스코프입니다. 그래서 메이트가 대신 조회하려면 각자의 개인 API 키가 필요해요.

- 키는 **사용자별**로 등록합니다(`/키등록`). 남의 이력을 몰래 보는 용도가 아니라,
  내 이력을 서버에서 함께 견줘 보기 위한 것입니다.
- 키는 **Fernet 대칭키로 암호화**해 보관하고, 넥슨 API 호출 시에만 복호화합니다.
- 처리·보관 방식은 [개인정보·보안](/privacy)에서 자세히 다룹니다.

## 챌린저스 서버 모드

챌린저스 서버 캐릭터를 등록하면, 비교·리더보드 명령에서 **모드를 챌린저스로**
골라 본서버와 **따로** 볼 수 있습니다. 두 서버의 데이터는 섞이지 않아요.

<Callout type="info">
  예를 들어 `/경험치` 리더보드나 `/스타포스` 비교를 본서버용과 챌린저스용으로
  각각 확인할 수 있습니다.
</Callout>
