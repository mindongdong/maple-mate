# 시작하기

<Note>
  글보다 화면이 편하다면 — **[영상으로 따라하는 5분 튜토리얼](/tutorial)** 에서
  초대부터 키 등록까지 한 번에 따라가 보세요.
</Note>

메이트는 **캐릭터를 한 번 등록해두면 계속 함께하는** 봇입니다.
서버에 초대만 하면 `/가이드` 와 경험치·공지·썬데이 알림은 누구나 바로 쓰고,
캐릭터와 넥슨 API 키를 등록하면 비교·리더보드·스케줄러까지 열립니다.

<BadgeLegend />

<Steps>

### 봇 초대하기

디스코드 서버에 메이트를 초대하세요. 서버 유저 한 명이 한 번만 진행하면 됩니다.
관리자 권한은 요구하지 않아요.
초대 직후부터 `/가이드`·`/경험치알림`·`/공지알림`·`/썬데이알림` 은 **등록 없이** 바로 쓸 수 있어요.

초대 링크를 열면 아래처럼 확인 화면이 떠요. 따로 고민할 건 없습니다 —
봇을 추가할 서버만 고르고 그대로 진행하면 설치 끝이에요.

  메시지를 보내기 위한 **최소한의 권한**이에요. 아무 문제 없으니 걱정하지 말고
  진행하시면 됩니다.
</Note>

### 캐릭터 등록 — `/캐릭터등록`

내 메이플 캐릭터의 닉네임으로 `/캐릭터등록` 을 실행하세요. 한 사람이 여러 캐릭터를
등록할 수 있습니다. 이 단계만 마치면 `/스펙`·`/아이템`·`/유니온`·`/경험치` 가 열려요.

### 넥슨 API 키 등록 — `/키등록`

스타포스·잠재 기록과 스케줄러 숙제는 넥슨 개인 API 키가 필요합니다.
API 키는 넥슨 계정 소유자가 본인의 상세한 정보(스타포스, 잠재, 스케줄러)를 조회하기
위해 사용하는 키입니다. 등록하면 **암호화해서 안전하게 보관**하고 API 키가 유출되지
않도록 설정했지만, 혹여나 유출되더라도 API 키는 메이플 캐릭터 정보 조회 외의
목적으로는 사용할 수 없으니 안심하시고 등록하셔도 됩니다.

**API 키 발급 방법** — 3분이면 끝나요.

1. [openapi.nexon.com](https://openapi.nexon.com) 에 접속해 넥슨 계정으로 로그인한 뒤,
   **마이 페이지 → 애플리케이션 등록** 으로 이동합니다.
2. 등록 폼을 아래처럼 채우고 등록합니다.

   | 항목 | 입력값 |
   | --- | --- |
   | 게임 선택 | 메이플스토리 |
   | 애플리케이션 타입 | **서비스 단계** |
   | 대표 언어 | 한국어 |
   | 출시할 서비스명 | 메이트 |
   | 서비스 소개 | 스케줄러 기능 및 큐브, 스타포스 내역 조회 |
   | 개발 환경 | 기타 (Pc App, 서버간 통신 등) |
   | URL 정보 | `https://maplemate.site/` |

3. **마이 페이지 → 애플리케이션 목록** 에서 방금 등록한 항목을 누르면
   기본 정보에서 **API Key** 를 확인할 수 있어요. 복사하세요.
4. 디스코드에서 `/키등록` 을 실행하고 키를 붙여넣습니다. 입력은 **본인에게만 보여요**.

<Note>
  API 키는 비밀번호처럼 다뤄 주세요. 다른 곳에 노출됐다면 넥슨 사이트에서 재발급하면 됩니다.
  메이트는 키를 암호화해 안전하게 보관해요 — 자세한 건 [개인정보·보안](/privacy)에서 다뤄요.
</Note>

### 대표 캐릭터 지정 — `/대표지정`

여러 캐릭터를 등록했다면, `/스펙`·`/경험치` 같은 명령에서 기본으로 쓸
**대표 캐릭터**를 `/대표지정` 으로 골라 주세요.

</Steps>
