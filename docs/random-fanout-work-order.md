# 작업지시서 — 무인자 랜덤 선정 + /경험치 대상 지정 + 명령별 지표 정렬

> 그릴링 확정 2026-07-04. 배경: 튜토리얼 10번 화면의 "대표 레벨 상위 최대 10명" 규칙이
> 상위권만 반복 노출돼 불공평 — 무인자 실행은 "본인 고정 + 랜덤"이 더 타당하다는 유저 판단.

## 결정 요약

### 1. 무인자 선정 규칙 개정 (ADR-0008 부분개정)

대상 명령 4개: `/아이템` `/유니온`(등록자 풀) · `/스타포스` `/잠재`(키 등록자 풀).

- 상한 K=10 유지. 선정 = **명령 실행 본인 무조건 포함 + 나머지 랜덤**.
- 랜덤은 비복원 추출(`random.sample`, 중복 구조적 불가) · 매 실행 독립(시드 없음, 테스트만 시드 주입).
- 풀 자체가 등록자뿐이므로 미등록 유저가 뽑힐 여지 없음.
- **본인이 풀에 없으면** 조용히 랜덤 10명 + 임베드에 사유별 안내 한 줄:
  - 캐릭터 미등록: "본인은 미등록이라 포함되지 않았어요. /캐릭터등록 부터 해주세요!"
  - 키 미등록(스타포스·잠재): "본인은 API 키 미등록이라 포함되지 않았어요. /키등록 부터 해주세요!"
  - 챌린저스 모드에서 챌 캐릭 없음: "본인은 챌린저스 캐릭터가 없어 포함되지 않았어요."
- `cap_by_level` → 랜덤 선정 헬퍼로 교체(comparison.py ADR-0008 블록). 대상 지정(최대 5명) 실행은 종전대로 상한 미적용.

### 2. /경험치 — 랜덤 미적용, 대상 지정만 추가

- 무인자·매일 10시 발송·DM 구독 전부 **기존 레벨 Top-10 기조 유지**(리더보드 정체성). 랜덤 없음.
- 대상 지정 파라미터 추가: 다른 비교 명령과 동일한 유저1~유저5 슬롯 5개.
  - 지정 시 그 유저들의 **대표 캐릭터만** 순위판+그래프 표시(전 캐릭터는 /내캐릭터 경험치 담당).
  - 미등록·데이터 없는 지정 유저는 빼고 표시 + "N명은 미등록/데이터 없음" 한 줄. 전원 불가면 안내만.
  - 지정 시 Top-10 상한 무의미(≤5명), 정렬은 기존 (레벨, exp%) 유지. 온디맨드 백필(ensure_guild_data)은 그대로.

### 3. 표시 정렬 — 명령별 핵심 지표 (무인자 + 지정 실행 공통)

| 명령 | 정렬 |
|---|---|
| /아이템 | 본인 맨 앞(대상에 있을 때만) + 나머지: 무인자=랜덤 선정 순서, 지정=입력 순서 |
| /유니온 | 유니온 레벨 내림차순 |
| /스펙 | 전투력 내림차순 (지정 필수 명령 — 지정 실행에 적용) |
| /스타포스 | 운빨 좋은 순 (상위 % 숫자 오름차순) |
| /잠재 | 사용 메소 내림차순 |
| /경험치 | 기존 (레벨, exp%) 유지 |

지표 정렬은 조회(fetch) 후 결과값 기준. 최고값 하이라이트 규칙은 기존 유지.

### 4. 무인자 푸터 — 항상 표시, 문구 분기 (기존 '잘렸을 때만'에서 변경)

- N ≤ 10: "등록자 전원(N명)을 비교했어요"
- N > 10: "등록자 N명 중 본인 포함 랜덤 10명을 비교했어요 · 특정 인원은 대상 지정(최대 5명)으로 볼 수 있어요"
- 스타포스·잠재는 명사 "키 등록자". 지정 실행에는 이 푸터 없음(종전대로).

### 5. 카피 통일

- /경험치: "등록 캐릭터들의 최근 7일 레벨 추이 그래프를 보여줍니다 (대상 지정 시 최대 5명만 비교)."
