## 맥락 (Context)

운빨수치(`meso_luck_percentile`, ADR-0002)가 상위 다수에게 "상위 0%"를 부여한다(이미지 `starforce_0628.png` — 상위 2명 동시 "상위 0%"). 지표 정의 자체는 옳다: `meso_luck_percentile`은 같은 등반을 MC로 5천 회 돌린 메소 분포 대비 백분위이고, 중앙값=상위 50%다.

**진짜 원인은 이벤트 무반영이다.** 모델은 *정가·무이벤트 파괴확률*로 기대치·분포를 잡는데, 실제 데이터에선 **15성+ 시도 1,335건 중 898건(67%)이 파괴확률 30% 감소 이벤트 중**에 일어났다. 파괴↓ → 재등반↓ → 실제 메소가 무이벤트 기대치보다 **구조적으로** 싸진다 → 거의 전원이 99~100 백분위로 압축 → 표시 반올림으로 "상위 0%". 즉 지표 정의(중앙값=50%, 분포 대비 백분위)는 옳으나 *기준선(무이벤트)*이 현실과 어긋난 것이다.

데이터 실증(로컬 DB = 운영 미러, `history_cache` 원본 jsonb):

- **데이터에 존재하는 이벤트**(API `starforce_event_list` per-record): 파괴확률 감소(`destroy_decrease_rate=30`, 고성 67%) · 강화비용 할인(`cost_discount_rate=30`, 51%) · 1+1(`plus_value=1`, 10성 이하 전용, 6%) · 5/10/15 100%성공(게임에서 폐지, 3%) · 복구비 할인(모델 복구비=0이라 무관) · 별캐치(달력 이벤트 아님).
- `starforce_event_range`가 이벤트 적용 성수를 명시(파괴감소=`15,16,…,21`, 할인=`0~29`) → 성수별 정확 반영 가능.
- **레벨 미상 장비 전수**(error_log)가 도달한 최고 성수 = 7성(블랙 완드·페어리 하트 등). 전부 11성 미달 → **11성 필터가 곧 레벨 미상 필터**. 11성+ 도달 67종은 전부 엔드게임 세트/시드 매칭 장비(슈페리얼 11성+ = 0건).

## 결정 (Decision)

운빨수치를 **이벤트 보정**한다 — "이벤트 때 강화했다"는 이유만으로 운이 좋아 보이지 않게, 강화 당시 조건 대비 "남들보다 잘 풀렸나"만 남긴다.

1. **기대값·분포·운빨을 강화 당시 이벤트 조건으로 보정한다.** 넥슨 API가 강화 기록마다 제공하는 `starforce_event_list`(+`starforce_event_range`)를 사용 — **재페치·스키마 변경 없음**(기존 캐시로 재집계). 성수별 마스크(`destroy_stars`·`discount_stars`)를 엔진에 주입한다.
2. **파괴감소 처리(공식 메커니즘):** `d' = d×0.7`, 줄어든 `0.3d`는 유지로, 성공 `p` 불변(합=1 보존). 파괴 없는 성수(d=0)는 무영향.
3. **메소 표시를 정가 → 실지불(할인 반영)로 바꾼다.** 총 사용 메소 = 실제 낸 메소(할인 시 정가×0.7, 각 시도의 *실제* 플래그). 기대도 동일 이벤트 조건이라 **손익은 여전히 할인-중립**(정가 폐기는 표시 금액만 바꿈, 0.7 균일 스케일은 순서 보존).
4. **집계 범위를 11성 이상(`before_star ≥ 11`) 시도로 한정한다.** 1+1(10성 이하 전용) 자동 무력화 + 저성 잡음·레벨 미상 장비 제거 + 자동 고레벨 한정(11성은 108레벨+에서만 가능). 11성에선 파괴가 없고(파괴 바닥 12성) 파괴→12 복귀도 ≥11 이라 등반이 자기완결한다. 성수 마스크는 **아이템별 성수 과반 투표**(동률→인정=보수적, 거짓 "운 좋음" 방지)로 구성한다.
5. **별캐치 성공/실패는 운에 포함(중립화 안 함).** 달력 이벤트가 아니라 본인 미니게임 → 현 "별캐치 상시 성공" 확률표 유지(자주 놓치면 운 나쁘게 나옴 = 의도).
6. **운빨 표시는 양극단 클램프 + 동점 손익순.** "상위 1% 미만"~"상위 99% 초과"로 클램프("상위 0%" 금지), 동점은 손익(이득) 큰 쪽이 위.
7. **레벨/미상 정리.** "레벨 미상 장비 제외" 임베드 필드 삭제(11성 필터로 미상 진입 차단 → 문구 생길 일 없음). 기준건수 `M/N건` → 단일 `N건`(분자=분모). 새 필드 "11성 이상 강화만 집계 (저성·이벤트 장비 제외)". 잔여 11성+ 미상(현재 0건)은 화면 조용히 제외 + `error_log`(시드 보강 신호, 유저 비노출). `MIN_AGGREGATE_LEVEL`·`EXCLUDED_ITEMS`는 11성 필터에 흡수돼 사실상 무발화 → 안전망으로 존치.

### 개정 (2026-06-28 추가) — 기댓값 대비 손익 컬럼 제거

본 ADR 초안은 **기댓값 대비 손익**을 실지불 기준 컬럼으로 표시하기로 했으나(원안), **표시에서 제거**한다(내부 계산값은 운빨 동점 정렬 타이브레이크로만 유지).

**근거:** 손익=`실지불 − 기댓값`인데, 기댓값은 `시작★→최종★` 마르코프 비용이고 `최종★ ≤ 시작★`(기간 윈도우 안에서 별을 못 올린 *미완성 등반*)이면 0이다 → 손익=`−실지불`(전액 손해). 마르코프 기댓값은 *완주*를 전제한 값이라 "아직 진행 중(미완주)"이라는 상태를 표현하지 못한다 — 21→22를 노리며 8억 쓰고 아직 22 못 단 사람을 "−8억 손해"로 부르는 건 틀린 프레임이다. 실증: 같은 등록자(동민)가 윈도우에 성공이 잡힌 기간엔 +23.9억, 전부 실패한 기간엔 −8.5억(=총 사용 메소와 절댓값 동일)으로 부호가 통째로 뒤집혔다. 절대 금액은 윈도우 cut 위치에 휘둘려 신뢰 불가.

**대신:** 표시는 **사실 그대로인 총 사용 메소(실지불 합) + 상대 지표 운빨 백분위 + 기준건수**만 노출한다. 운빨도 같은 미완성 아티팩트를 공유하나(무진행 spend 가 actual 에만 더해져 백분위를 끌어내림) **0~100 제한 상대 순위**라 절대 금액보다 덜 오해되므로 재미용 상대 지표로 수용한다(무진행 운빨 보정은 별도 이슈로 보류).

## 근거 (Rationale)

- 이벤트 무반영이 "상위 0%"의 67% 책임(데이터). **정가 단독 폐기가 아니라** 양쪽(기대·실지불) 보정이라 손익은 할인-중립으로 유지된다(CONTEXT §165 의도 보존).
- 11성 필터가 레벨 미상(전수 ≤7성)·1+1·저성 잡음을 **한 규칙으로** 해소(증거: unmatched 전수 도달성수·`reachable_star`).
- 별캐치는 달력 외부요인이 아니라 플레이어 행동 → 운으로 측정하는 게 타당.
- **실데이터 재집계 확인:** 로컬 DB 5명 재집계 결과 OLD "상위 0%"가 NEW "상위 29%"로, 백분위가 한쪽(0~15%)에 떼몰리던 것이 **8·25·29·51·72%로 분산**됐고, 손익도 합리화(라딘라면 −101억→−5.4억)됐다.

## 검토한 대안 (Alternatives Considered)

- **표시만 수정(상위 0% 숨김):** 이벤트 편향이 잔존 → 여전히 떼몰림. 기각.
- **비교군 내 상대화("전체 메이플 대비"):** 의미 상실. 기각.
- **성공확률 백분위(ADR-0002 ② 재도입):** 손익과 정렬 어긋남(고성 한방 왜곡) — 이미 ADR-0002에서 기각된 길.
- **모델 파괴확률 캘리브레이션:** OFF 표본에서도 모델이 현실보다 높아 보이나, 이는 이벤트 보정과 **별도 이슈**(신규 작업지시서로 분리). 본 ADR 범위 밖.

## 결과 (Consequences)

**긍정**
- "상위 0%" 떼몰림 해소 — 같은 이벤트 조건 대비 "잘 풀렸나"만 남아 백분위가 분산된다.
- 손익·총 메소가 실지불(체감 금액)과 일치하면서도 할인-중립(기대도 동일 조건).
- 11성 필터가 미상·1+1·저성을 한 규칙으로 정리 → 표가 단순(`N건`)·고레벨 한정.

**부담 / 잔류**
- ADR-0002의 "정가·무이벤트" 전제는 *기준선만* 이벤트 보정으로 개정(메소 기반·정렬 일관성·중립점 결론은 유효).
- 저성만 강화한 대상은 "11성 이상 강화 기록이 없어요"로 빠진다(기록없음 분기 재사용).
- **미해결 별도 이슈:** 모델 파괴확률이 현실(OFF 표본)보다 높아 보임 → 캘리브레이션은 후속.
