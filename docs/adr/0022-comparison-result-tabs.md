# ADR-0022 — 비교 결과 탭 전환 (스펙·아이템 부위·유니온)

- **상태:** 채택 (Accepted)
- **일자:** 2026-10-12
- **관련 문서:** [comparison-tabs-work-order.md](../comparison-tabs-work-order.md)(빌드 단위·테스트), [ADR-0021](0021-nickname-guest-targets.md)(대상 해석 — 게스트 포함 Target 목록), [ADR-0008](0008-unspecified-comparison-fanout-cap.md)(무인자 K — 스펙 5 / 아이템·유니온 10), [comparison_tabs.py](../../maple_mate/bot/comparison_tabs.py)

## 맥락 (Context)

같은 사람들을 `/스펙` → `/아이템` → `/유니온`으로 이어 보려면 매번 대상을 다시 입력해야 했다.
무인자 실행은 매번 랜덤이라 같은 집합을 다시 볼 수조차 없었다. 세 명령은 같은 대상 모델(`Target` 목록)과
같은 조회 머신(`fetch_each`)을 쓰므로, 한 번 해석한 집합으로 다른 비교를 다시 만드는 것은 렌더 문제다.

## 결정 (Decision)

1. **대상 명령 = `/스펙`·`/아이템`·`/유니온`.** 결과 메시지에 버튼 `스펙`·`유니온` + 아이템 부위 Select(24개)를
   붙인다. `/경험치`(리더보드 의미)·`/내캐릭터`(유니온 없음·캐릭터 타깃 모델)·이력류는 제외한다.
2. **실행자만, 메시지 제자리 교체.** 타인 클릭은 페이지네이터와 같은 ephemeral 거부다. 새 메시지는 만들지 않는다
   (채널 도배 방지).
3. **대상 집합 고정.** 최초 해석한 `targets` + 사전 실패 `missing` + 무인자 안내 줄을 View가 보관해 그대로
   재사용한다. 재해석·재랜덤은 없다.
4. **스펙 탭 상한 5.** 집합이 6명 이상이면(무인자 아이템·유니온은 최대 10) 앞 5명만 조회하고
   "스펙은 최대 5명 — 앞 5명만 비교했어요" 줄을 붙인다. 본인은 선정 때 맨 앞이라 보존된다(1명당 ≈13콜 비용 근거).
5. **연타 방지 = View 단위 락.** 클릭 즉시 전 컴포넌트를 비활성으로 응답하고(3초 기한), 조회가 끝나면 결과와
   재활성 컴포넌트를 반영한다. 진행 중 클릭은 조용히 확인만 한다. 슬래시 쿨다운은 컴포넌트에 적용되지 않지만,
   스펙 단기 캐시·과거 전투력 영구 캐시 + 락이면 충분해 별도 시간 쿨다운은 두지 않는다.
6. **timeout 600초**(원 followup 웹훅 토큰 15분 안). 만료 시 컴포넌트를 제거한다(`view=None`).
7. **실패 처리.** 전환한 탭이 전원 실패면 실패 임베드로 교체하고 컴포넌트는 유지한다(다른 탭으로 복귀 가능).
   예외는 로그 후 컴포넌트를 재활성화하고 탭은 그대로 둔다.
8. **구조.** 3종은 `ComparisonMessage(embed, file|None)`를 돌려주는 빌더(`build_spec_message`·
   `build_item_message`·`build_union_message`)로 추출한다. View는 빌더를 주입받는다 — 도메인이 이미 `bot`을
   import 하므로 `bot`이 도메인을 import 하면 순환이 생긴다.

## 검토한 대안 (Alternatives Considered)

- **누구나 조작 + 새 메시지** — 다른 사람도 볼 수 있지만 메시지가 쌓인다. 기각.
- **persistent view(재시작 후 복구)** — custom_id에 대상 집합을 직렬화해야 하고 수명 10분짜리 UI에 과하다. 기각.
- **탭마다 시간 쿨다운** — 캐시 히트가 대부분이라 불필요한 제약. 락으로 대체.

## 결과 (Consequences)

- 같은 대상의 세 비교를 클릭만으로 오간다. 버튼을 누르지 않으면 기존 출력과 동일하다(컴포넌트만 추가).
- 봇 재시작 후의 클릭은 "상호작용 실패"가 된다(Bitik·페이지네이터와 같은 감수).
- 스펙 탭의 무인자 안내 줄은 최초 명령 기준이다(예: 아이템 10명 → 스펙 5명이면 절단 줄이 추가로 붙는다).
