# ADR-0025 — 키 기반 계정 동기화 (`character/list`)

- **상태:** 채택 (Accepted)
- **일자:** 2026-10-16
- **관련 문서:** [account-character-import-work-order.md](../account-character-import-work-order.md)(최종 설계·G0 결과 §7), [ADR-0023](0023-character-management-hub.md)(관리 허브), [ADR-0024](0024-history-cache-account-key.md)(이력 캐시 계정 식별자), [ADR-0006](0006-multi-character-data-model.md)(멀티 캐릭터·상한 10), [ADR-0009](0009-challengers-realm-model.md)(챌린저스 realm)

## 맥락 (Context)

캐릭터는 `/캐릭터등록 닉네임`으로 하나씩만 등록할 수 있었고, 닉 변경·레벨업은 재등록해야 반영됐다. 넥슨
`character/list`는 개인 키 하나로 그 계정의 전체 캐릭터(ocid·닉·월드·직업·레벨)를 한 번에 준다. 구현 전에 운영자
실키로 G0 스파이크를 돌린 결과:

- 목록 ocid가 공개 `/id`(앱 키) ocid와 같았다(5/5).
- 스키마가 문서와 같았다.
- 레벨이 실시간이었다(5/5).
- 캐릭터가 **96개**(월드 11종)였고 응답은 0.15초였다.

## 결정 (Decision)

1. **진입점 = `/캐릭터목록` 허브 `🔄 계정 동기화` + `/키등록` 직후.** 새 명령은 없다. 원안의 `/캐릭터가져오기`는 폐기한다.
2. **목록은 1콜로 받아 View가 보관한다.** 페이지 이동·선택·가져오기·갱신은 모두 그 데이터로 처리한다(넥슨 추가 호출 0).
3. **ocid 대조 3분류:**
   - 등록됨 + 계정에 있음 → 닉·레벨·월드를 **자동 갱신**한다.
   - 계정에만 있음 → **가져오기 후보**로 보여준다.
   - 등록됨 + 계정에 없음 → **정리 제안**만 한다. 자동 삭제는 금지한다. 개인 키는 넥슨 계정 하나에만 묶여 있어서,
     다른 계정 캐릭터나 닉으로 직접 등록한 캐릭터도 정상적으로 여기에 걸린다.
4. **후보 UI = 레벨 높은 순 5개씩 페이지.** 96개 규모에서 디스코드 Select 상한(25)을 넘는 문제를 해결한다(사용자 결정).
   - 페이지를 넘어도 선택을 유지한다.
   - 남은 자리(10 − 등록 수)까지만 고를 수 있다.
   - 커밋 직전에 상한을 다시 확인한다.
   - 월드 필터·저레벨 숨김은 두지 않는다. 레벨순이라 저레벨은 자연히 뒤 페이지로 간다.
5. **챌린저스 월드(`챌린저스`·`챌린저스N`)는 후보에서 제외한다**(사용자 결정, 시즌 종료). `is_challengers()`는 시즌 스위치로
   꺼져 있어서 world 접두를 직접 판정한다.
6. **주기적 자동 동기화는 하지 않는다**(사용자 결정). 화면을 열 때만 갱신한다.
7. **실패해도 키 등록은 유지한다.** `/키등록` 직후 목록 조회가 실패하면 성공 안내와 재시도 경로를 보여준다.
8. **관리 화면 공통 동작은 기반 클래스로 묶는다.** 먼저 응답하기·연타 무시·타임아웃 정리를 `_ManagedView`로 추출해
   허브와 동기화 화면이 공유한다. 화면을 전환할 때 이전 View는 `stop()`한다.

## 검토한 대안 (Alternatives Considered)

- **레벨 상위 25개 메뉴 1개(원안)** — 96개 계정에서 부캐를 고를 수 없다. 기각.
- **월드 필터 + 25개 페이지** — 사용자가 단순한 5개 페이지를 선택했다. 기각.
- **계정에 없는 등록 캐릭터 자동 삭제** — 다른 계정 캐릭터를 잘못 지운다. 기각.
- **주기적 자동 갱신(일일 잡)** — 필요성이 낮다(사용자 결정). 기각.

## 결과 (Consequences)

- 키 등록 직후 클릭 몇 번으로 여러 캐릭터를 등록하고, 닉 변경·레벨업을 한 번에 반영할 수 있다.
- 동기화 1회 = 개인 키 1콜(키별 스로틀 — 다른 유저·앱 키와 무관).
- 동기화로 레벨이 실시간 값이 되므로 대표 자동 선택(최고 레벨)과 `/내캐릭터` 정렬이 정확해진다.
