# ADR-0013 — 스케줄러 숙제 표시: 필드 파생 카테고리 분류 (요약형 폐기)

- **상태:** 채택 (Accepted) — [ADR-0012](0012-scheduler-reminder-per-user-dm.md) 결정 5(표시 규칙)를 **개정(supersede)**, 결정 1~4·6·7은 불변.
- **일자:** 2026-06-27
- **관련 문서:** [CONTEXT.md](../../CONTEXT.md)(스케줄러 숙제), [docs/api/scheduler.md](../api/scheduler.md)(실 필드 의미·실호출), [docs/scheduler-design-handoff.md](../scheduler-design-handoff.md)(디자인 핸드오프), [service.py](../../maple_mate/scheduler/service.py)(파싱·카테고리·렌더), [broadcast.py](../../maple_mate/scheduler/broadcast.py)(임베드 조립)
- **이력:** `/grill-with-docs` 그릴링(2026-06-27, 사용자 요구 "완료/미완료를 확실히, 내가 뭘 더 해야하지가 즉시 보이게") + **라이브 9캐릭 실 API 필드 조사**로 분류 규칙 확정.

## 맥락 (Context)

ADR-0012 결정 5의 첫 as-built("요약형": 진행중만 게이지·미시작 한 줄 접기·완료 수만)가 사용자 검수에서 요구를 못 맞췄다. 핵심 불일치:

1. **"할 일"이 가장 안 읽혔다.** 요약형은 진행 중을 부각하고 **미시작(=해야 할 일 대부분)을 접힌 한 줄**로 눌렀다. "내가 뭘 더 해야하지?"가 제일 안 보였다.
2. **"0/100 텍스트 벽"의 원인을 오진했다.** 라이브 조사 결과 벽의 정체는 **일일 퀘스트**(`type=quest`, `quest_state=1`, `now/max=0/100`은 무의미)였다. 미시작 항목을 보여준 게 문제가 아니라 **퀘스트에 무의미한 점수 게이지를 붙인 것**이 문제였다.
3. **콘텐츠 성격이 제각각인데 한 게이지로 뭉갰다.** 퀘스트(완료/미완료)·몬스터파크(회수)·길드 점수(상한 없음)·보스(완료/미완료)가 모두 `now/max` 한 모양이었다.

사용자는 카테고리를 "제대로 나눠서" 표시하길 원했다(퀘스트=완료/미완료, 몬스터파크=회수, 길드=점수, 보스=주/일/월). 그러나 ADR-0012는 **"콘텐츠명 하드코딩 금지"**(자유 문자열 → 리네임 시 조용히 깨짐, "수로 핀 고정"을 명시 기각)와 **"일일/주간/보스 3섹션"**을 불변으로 잠갔었다.

## 결정 (Decision)

**표시를 요약형에서 폐기하고, API 필드로 파생한 카테고리 세분화 임베드로 바꾼다. 카테고리는 콘텐츠명이 아니라 `type`/`quest_state`/`max_count`/`cycle` 필드로 결정한다(이름 하드코딩 0).** ADR-0012의 "3섹션 불변"은 폐기하되 "콘텐츠명 하드코딩 금지"는 **필드 파생으로 보존**한다.

**라이브 9캐릭 실 API 조사(2026-06-27)로 확정한 필드 파생 규칙:**

| 조건 | 카테고리 | 표시 | 완료 판정 |
|---|---|---|---|
| `type=="quest"` | 퀘스트 | 완료/미완료 (게이지 없음) | `quest_state=="2"` 완료 / `"1"` 미완료 / `"0"` 기타→**제외** |
| `type=="contents"` & 이름 `[길드]` 프리픽스 | 길드 콘텐츠(점수제: 주간 미션 포인트·플래그 레이스·지하 수로) | `now`만(상한 없음) | **완료 개념 없음** |
| `type=="contents"` & `max_count>1` | 회수형(몬스터파크) | `🟡 n/m`(진행중) | `now>=max` |
| `type=="contents"` & 그 외(`max` 0/1) | 완료/미완료(에르다·**에픽던전·무릉** 등) | 완료/미완료 | `now>0` |
| boss | 보스 | `cycle`별 그룹·완료/미완료·난이도 한글 | `complete_flag=="true"` |

> **개정(2026-06-27, 사용자 피드백):** ① **진행바(▰▱) 제거** — `남은 N + 완료/총` 숫자만으로 충분. ② **`max==0` 일괄 점수형이 과했음**: **`[길드]` 프리픽스만 점수제**(길드 콘텐츠 = 주간 미션 포인트·플래그 레이스·지하 수로), **에픽던전·무릉 등 비길드 `max==0`은 완료/미완료**(`done=now>0`)로 주간/일일 콘텐츠에 편입. 길드 식별은 특정 이름이 아니라 NEXON `[길드]` 구조 프리픽스(신규 길드 콘텐츠 자동 분류, `strip_prefix`와 동류라 "하드코딩 금지" 무위반).

**표시 규칙(렌더):**
- **할 일 우선(todo-first):** 미완료를 개별로 전부 나열(필드 1024 초과만 `…외 N개`), 완료는 `✅ 완료 N개 · 이름…` 한 줄로 접는다.
- **진행 게이지는 회수형(max>1)의 `0<now<max`에만.** 퀘스트·길드·완료미완료는 `⬜`/`✅` 이진 표기(0/100 도배 소멸).
- **섹션 헤더 = `남은 N + 완료/총`(진행바 없음).** "남은 N"(=할 일)을 헤드라인으로.
- **부제 = `Lv·월드` + `🔥 남은 숙제 N개 (완료/총)`.** 길드(점수제)·qs0은 집계 제외. 잔여 0이면 `✅`로 스왑.
- **상태색 2색:** 잔여 0이면 초록, 있으면 브랜드 오렌지(임베드 단색 = 거친 "할 게 있나" 신호).
- **길드 콘텐츠(점수제) todo 신호:** `now==0`은 `⬜`(아직 안 함), `now>0`은 `🔹 이름 점수`. 단 **수치 카운트(남은 N)엔 불포함**(완료 목표가 없어 혼선 방지).
- **보스 cycle 그룹:** `bossDaily`/`bossWeekly`/`bossMonthly` 3종(라이브 실측). 주간 보스 필드에만 넥슨 주간 처치 카운터 `(처치 c/12)` 부가. 난이도 `easy/normal/hard/chaos/extreme → 이지/노멀/하드/카오스/익스트림`.

**불변 유지(ADR-0012):** `registration_flag=="true"` 필터, 온디맨드·DM **빌더 공유**(`build_homework`/`build_embed`), 조용한 스킵+fail-fast(결정 1~4·6·7), **콘텐츠명 하드코딩 금지**(이제 필드 파생으로 충족).

## 검토한 대안 (Alternatives Considered)

- **요약형 유지(미세 조정만)** — *기각.* 미시작을 접는 구조 자체가 "할 일 즉시 파악"과 충돌. 2회 반복(체크리스트→요약형)에도 요구 미충족.
- **콘텐츠명 하드코딩(몬스터파크/수로/플래그 이름 매칭)** — *기각.* ADR-0012가 명시 기각한 방식. 넥슨 리네임/신규 콘텐츠 시 조용히 오분류. 필드(`type`/`max_count`/`cycle`)로 동등 이상 달성 가능함을 라이브로 확인.
- **PIL 이미지 카드(Option C)** — *보류.* 열 정렬·디자인 최상이나 노력 큼·모바일 글자 작아짐·탭 불가. 임베드 필드 파생으로 요구가 충족돼 현 시점 불필요(임베드 한계가 명확해지면 재검토).
- **4분류 보스(주/일/월/시즌)** — *불가.* 라이브 실측상 `cycle`은 `bossDaily/Weekly/Monthly` 3종뿐이고 "시즌 보스"(메이린)도 `bossWeekly`로 온다. 3분류로 확정.
- **주간 보스 한도 상수 12 고정** — *기각(폴백만 채택).* 실 API가 12를 반환하므로 `weekly_boss_clear_limit_count`를 우선 쓰고, `0`/이상값일 때만 12로 폴백((0,0) 캐릭 관측).

## 결과 (Consequences)

**긍정**
- "내가 뭘 더 해야하지?"가 `⬜` 목록 + 헤더 `남은 N` + 부제 전체 잔여로 즉시 파악. 라이브 3캐릭 렌더로 검증.
- 일일 퀘스트 `0/100` 텍스트 벽 소멸(이진 표기). 카테고리별 성격에 맞는 표기(퀘/회수/길드/보스).
- 이름 특수케이스 0 → 넥슨 리네임/신규 콘텐츠에 견고(필드 + `[길드]` 구조 프리픽스만 의존).

**부담 / 잔류**
- **파서가 신규 필드(`type`/`quest_state`/`cycle`)를 캡처**해야 함(`ContentItem`/`BossItem` 확장). 넥슨이 필드 의미를 바꾸면 분류가 흔들린다.
- **`[길드]` 프리픽스 의존:** 길드 콘텐츠 식별은 `[길드]` 구조 프리픽스에 기댄다. NEXON이 이 프리픽스 규칙을 바꾸면 길드가 일반 콘텐츠로 떨어진다(특정 이름보다는 견고하나 무위험 아님).
- **비길드 `max==0`은 `done=now>0` 이진**(에픽던전·무릉). 완료 "목표"가 없는 누적을 "했나/안했나"로 환원 — 1회 이상이면 완료로 본다(사용자 합의).
- **난이도·cycle 한글/라벨 매핑은 enum 가정**(영문 enum이 바뀌면 미상은 원문 노출). bounded enum이라 위험 작음.
- **주간 보스 미처치가 많으면 긴 목록**(라이브: 최대 14줄). "전부 나열" 결정의 의도된 체크리스트지만, 더 길어지면 난이도별 묶기/접기를 후속 검토(표시 규칙 영역).
- **"시즌 보스"를 별도 분류 못 함**(cycle 없음). 메이린은 주간 보스에 섞인다.
